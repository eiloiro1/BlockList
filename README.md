# Vitta Social Blocklist

Lista de bloqueio de redes sociais utilizada pela Clínica Vitta.

Baseada em:

StevenBlack Hosts - social-only

Objetivo:

- Bloquear redes sociais
- Permitir WhatsApp
- Permitir YouTube

A lista é regenerada automaticamente pelo GitHub Actions.
